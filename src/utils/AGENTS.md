# 工具函数 (utils)

## 模块说明

通用工具函数集合，包含格式化、验证、转换等工具。

## 目录结构

```
utils/
├── format.ts       # 格式化工具
├── validate.ts     # 验证工具
├── storage.ts      # 存储工具
├── request.ts      # 请求工具
├── ...
```

## 核心工具

| 工具 | 说明 |
|------|------|
| format | 日期、金额、文件大小格式化 |
| validate | 表单验证规则 |
| storage | LocalStorage/SessionStorage 封装 |
| request | Axios 请求封装 |
| crypto | 加密解密工具 |
| color | 颜色转换工具 |
