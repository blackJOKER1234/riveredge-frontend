# 类型定义 (types)

## 模块说明

TypeScript 类型定义文件，包含业务类型、组件 Props 类型等。

## 目录结构

```
types/
├── index.ts       # 导出入口
├── api.d.ts       # API 类型
├── components.d.ts # 组件类型
└── ...
```

## 类型分类

| 类型 | 说明 |
|------|------|
| API 类型 | 请求参数、响应数据类型 |
| 组件类型 | React 组件 Props 类型 |
| 业务类型 | 业务实体类型定义 |
| 工具类型 | 工具函数参数/返回值类型 |
