# 数据集管理 (datasets)

## 模块说明

数据集设计与管理，支持 SQL 查询、数据聚合、可视化配置。

## 目录结构

```
pages/system/datasets/
├── list/       # 数据集列表
└── designer/   # 数据集设计器
```

## 核心功能

- **数据源选择**：选择连接的数据源
- **SQL 编辑器**：编写数据查询 SQL
- **字段映射**：字段别名、类型转换
- **数据预览**：预览查询结果
- **参数配置**：支持动态参数

## 技术要点

- **查询优化**：SQL 语法校验
- **缓存策略**：数据集结果缓存
- **权限控制**：数据集访问权限

## API

- `GET /datasets` - 获取数据集列表
- `POST /datasets` - 创建数据集
- `PUT /datasets/:id` - 更新数据集
- `GET /datasets/:id/preview` - 预览数据
