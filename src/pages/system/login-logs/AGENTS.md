# 登录日志 (login-logs)

## 模块说明

用户登录日志记录与查询，记录登录时间、设备、IP 等信息。

## 目录结构

```
pages/system/login-logs/
└── index.tsx       # 主页面
```

## 核心功能

- **登录记录**：查看登录历史
- **异常检测**：标记异常登录
- **统计报表**：登录趋势分析
- **导出功能**：导出登录日志

## 记录信息

| 字段 | 说明 |
|------|------|
| 用户 | 登录用户名 |
| 时间 | 登录时间 |
| IP | 登录 IP 地址 |
| 设备 | 登录设备信息 |
| 结果 | 成功/失败 |
| 原因 | 失败原因 |
