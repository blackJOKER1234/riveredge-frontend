# 菜单配置 (menus)

## 模块说明

系统菜单配置模块，支持菜单的增删改查、拖拽排序、图标选择等。

## 目录结构

```
pages/system/menus/
├── index.tsx                    # 主页面
├── CustomMenuLayoutEditor.tsx   # 自定义布局编辑器
└── ...
```

## 核心功能

- **菜单管理**：目录、菜单、按钮三级结构
- **拖拽排序**：菜单顺序拖拽调整
- **图标选择**：Ant Design 图标选择器
- **外部链接**：支持配置外部 URL

## 技术要点

- **菜单树**：递归菜单树结构
- **权限绑定**：菜单与权限点绑定
- **多语言**：菜单名称多语言支持

## API

- `GET /menus` - 获取菜单树
- `POST /menus` - 创建菜单
- `PUT /menus/:id` - 更新菜单
- `DELETE /menus/:id` - 删除菜单
