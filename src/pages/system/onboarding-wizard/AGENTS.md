# 初始化向导 (onboarding-wizard)

## 模块说明

新租户初始化向导，引导用户完成系统初始配置。

## 目录结构

```
pages/system/onboarding-wizard/
├── index.tsx              # 主页面（约90KB）
├── roleLaunchData.ts      # 角色初始数据
└── systemLaunchData.ts    # 系统初始数据
```

## 向导步骤

1. **选择行业模板**：制造业/零售业/服务业等
2. **基础配置**：公司名称、规模、时区
3. **组织架构**：部门、岗位初始数据
4. **权限模板**：选择预设权限模板
5. **导入数据**：导入现有数据（如有）
6. **完成确认**：检查配置并启动

## 技术要点

- **步骤管理**：分步骤引导
- **数据预览**：导入数据预览
- **进度保存**：中断后可继续

## API

- `GET /industry-templates` - 获取行业模板
- `POST /onboarding/init` - 提交初始化数据
