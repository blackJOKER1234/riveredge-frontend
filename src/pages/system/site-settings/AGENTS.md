# 站点设置 (site-settings)

## 模块说明

租户站点设置模块，包含 logo、主题、首页配置、邮件短信配置等。

## 目录结构

```
pages/system/site-settings/
└── index.tsx    # 主页面（约90KB，大型配置页面）
```

## 核心功能

- **基本信息**：站点名称、Logo、域名
- **主题配置**：主题色、背景色、字体
- **首页配置**：默认首页、自定义首页
- **邮件配置**：SMTP 邮件发送设置
- **短信配置**：短信服务商配置
- **水印配置**：文字/图片水印

## 技术要点

- **配置分组**：分组展示不同类型配置
- **实时预览**：配置修改实时预览效果
- **配置校验**：必填项与格式校验

## API

- `GET /site-settings` - 获取站点设置
- `PUT /site-settings` - 更新站点设置
