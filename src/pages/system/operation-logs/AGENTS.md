# 操作日志 (operation-logs)

## 模块说明

系统操作日志记录与查询，记录用户的关键操作行为。

## 目录结构

```
pages/system/operation-logs/
└── index.tsx       # 主页面
```

## 核心功能

- **日志查询**：按时间、用户、操作类型查询
- **日志详情**：查看操作详细变更
- **日志导出**：导出操作日志
- **异常标记**：标记异常操作

## 记录内容

| 类型 | 说明 |
|------|------|
| 数据变更 | 创建、修改、删除记录 |
| 权限变更 | 用户角色变更 |
| 配置变更 | 系统配置修改 |
| 登录登出 | 登录登出记录 |
| 审批操作 | 审批通过/拒绝 |

## API

- `GET /operation-logs` - 获取操作日志
- `GET /operation-logs/:id` - 获取日志详情
