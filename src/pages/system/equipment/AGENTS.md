# 设备管理 (equipment)

## 模块说明

设备台账管理，包含设备档案、点检、保养、维修等功能。

## 目录结构

```
pages/system/equipment/
├── list/       # 设备列表
└── trace/      # 设备追溯
```

## 核心功能

- **设备档案**：设备基本信息、技术参数
- **点检计划**：日常点检项目与周期
- **保养计划**：定期保养任务
- **故障报修**：设备故障登记与处理
- **设备追溯**：设备全生命周期追溯

## 技术要点

- **设备编码**：唯一编码规则
- **附件管理**：设备图纸、说明书
- **二维码**：设备二维码扫描

## API

- `GET /equipment` - 获取设备列表
- `POST /equipment` - 创建设备
- `POST /equipment/:id/maintenance` - 提交保养记录
- `POST /equipment/:id/fault` - 提交故障记录
