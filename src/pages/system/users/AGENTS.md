# 用户管理 (users)

## 模块说明

系统用户管理模块，包含用户列表、用户详情、用户导入导出。

## 目录结构

```
pages/system/users/
├── list/           # 用户列表
└── components/     # 用户组件
```

## 核心功能

- **用户列表**：分页展示、筛选、搜索
- **用户详情**：查看用户完整信息
- **用户编辑**：新增、编辑、禁用用户
- **批量导入**：Excel 批量导入用户
- **批量导出**：用户数据导出

## 技术要点

- **密码策略**：密码强度校验、定期更换
- **用户状态**：启用/禁用/锁定
- **用户类型**：管理员、普通用户、外部用户

## API

- `GET /users` - 获取用户列表
- `POST /users` - 创建用户
- `PUT /users/:id` - 更新用户
- `DELETE /users/:id` - 删除用户
- `POST /users/import` - 导入用户
